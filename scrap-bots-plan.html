Scrap Bots Simulator

A collect-and-upgrade simulator set in a scrapyard. Players pick up scrap, sell it, buy better tools, and build robot helpers that collect for them. This page is the full plan to review before any work starts in Roblox Studio.

1Concept

The simulator genre has the best-understood way to earn on Roblox, and new content is cheap to add. Most simulators use pets, mining or fishing. A scrapyard with robots gives the same loop a look that is less used, and robots replace pets as the thing players collect and show off.

GenreSimulator with light tycoon elements
AudienceAges 8 to 14, mostly on phones
Session target15 to 25 minutes
Server size12 players
Team assumed1 developer, 10 to 15 hours a week
Time to launch8 weeks

The one-line pitch for the game page: "Collect scrap, build robots, take over the junkyard."

The name is a working title. Check it is not taken on Roblox before making the icon.

2Core loop

  1. CollectTap scrap piles until the backpack is full.
  2. SellWalk to the crusher and turn scrap into coins.
  3. UpgradeBuy a better tool and a bigger backpack.
  4. Build botsOpen crates to get robots that collect for you.
  5. UnlockPay coins to open the next zone with richer scrap.
  6. RebirthReset progress for a permanent coin multiplier.

One lap of collect, sell and upgrade should take under 90 seconds in the first zone. Every lap must end with the player able to afford something, or seeing how close they are to it.

Three layers of goals

  • Seconds: fill the backpack. Numbers pop up on every tap.
  • Minutes: afford the next tool or crate.
  • Hours and days: unlock the next zone, complete the bot index, climb the rebirth leaderboard.

Robots

Robots follow the player, collect scrap automatically and add a coin multiplier. A player equips 3 at a time. Crates are bought with coins earned in the game, never directly with Robux. Each zone has its own crate with 5 robots, so version 1 ships with 20 robots.

RarityCrate oddsCoin multiplierExample
Common60%+10%Rusty Roller
Uncommon28%+25%Toaster Tank
Rare10%+60%Forklift Fred
Epic1.9%+150%Chrome Hound
Legendary0.1%+500%Titan Crusher

Three robots of the same kind merge into a "Polished" version worth double. This gives duplicate robots a use and keeps players opening crates.

Rebirth

  • First rebirth costs 2,500,000 coins. Each later one costs 2.5 times the previous.
  • Resets coins, tools, backpacks and zone unlocks.
  • Keeps robots, gamepasses and the bot index.
  • Grants +50% coins permanently per rebirth, plus one extra robot slot at rebirths 1, 5 and 15.
  • Target: a new player reaches the first rebirth after 60 to 90 minutes of play.

Reasons to come back

  • Daily reward: a 7-day streak, with a guaranteed Rare robot on day 7.
  • Playtime gifts: free rewards at 5, 15, 30 and 60 minutes in a session.
  • Codes: redeemable codes posted with each update.
  • Bot index: a collection book with a reward for completing each zone.
  • Leaderboards: most rebirths and most scrap collected, shown in the hub.

Left out of version 1 on purpose

Trading, limited-time events, guilds, quests and a battle pass. Each one is a later update. Trading in particular needs anti-scam protections and should wait until the game has an audience.

Other income

  • Private servers: 100 Robux a month, for players who want the scrap to themselves.
  • Creator Rewards: Roblox pays creators for bringing in and keeping active spenders. This programme replaced the older Premium Payouts in 2025. Read the current terms on the Creator Hub before counting on it.
  • Immersive and rewarded video ads: add after launch, once daily players are steady. They have age and eligibility rules.
Rule to follow on crates. Roblox requires games to show the odds for any random item that can be bought with Robux, and some countries restrict them entirely. This plan sells crates for in-game coins only and shows the odds on every crate anyway. Because coin packs can be bought with Robux, check PolicyService for each player and hide what must be hidden where restrictions apply.

Player data

Saved with a session-locking library such as ProfileStore, which prevents the duplicate-item bugs that come from a player's data loading on two servers at once.

{
  coins = 0, scrap = 0, rebirths = 0,
  tool = "MagnetGlove", backpack = "LunchSack",
  zones = { "BackyardHeap" },
  bots = { { id = "RustyRoller", polished = false, equipped = true } },
  index = {}, boosts = {}, codesUsed = {},
  daily = { streak = 0, lastClaim = 0 },
  purchases = {},   -- receipt ids already granted
  stats = { totalScrap = 0, playtime = 0 },
  version = 1
}

Rules that prevent cheating and lost purchases

  • The server decides every amount. The client only says "I tapped pile 14". The server checks distance, tap rate and backpack space, then works out the reward.
  • No remote accepts a coin value, a price or an item name without checking it against the config.
  • ProcessReceipt grants the item, records the receipt id in saved data, and only then confirms the purchase. A crash in between must never lose or double a purchase.
  • Gamepass ownership is checked on the server with UserOwnsGamePassAsync and cached per session.
  • Crate rolls happen on the server. The client only plays the opening animation.

Performance on phones

  • Robots are simulated as numbers on the server. Their models and movement exist on each client only.
  • Scrap piles are reused from a pool, not created and destroyed.
  • Streaming is on, so far zones do not load on weak devices.
  • All buttons are thumb-sized and the HUD is tested at phone resolution first.

Assets

Low-poly, bright, chunky shapes. Robots are built from a shared kit of parts so 20 robots need about 30 unique pieces. Avoid free Toolbox models with scripts inside them, since some contain backdoors.

8Launch and growth

  • Icon: one large robot face, bright background, no small text. Make three versions and test which gets more clicks.
  • Title: include an update tag, such as "[NEW] Scrap Bots Simulator".
  • Ads: start with a small sponsored-ad budget to get the first few hundred players. Raise it only if day-1 return rate is above target.
  • Community: a Roblox group with a join reward in the game, and a place to post codes.
  • Update rhythm: something new every one to two weeks for the first two months.

What different sizes could earn

Roblox keeps 30% of each gamepass and developer product sale. Robux convert to cash through DevEx. The rate used below is US$0.0038 per Robux and the minimum cash-out is 30,000 earned Robux. Confirm both on the DevEx page, since they change.

These rows are arithmetic on assumed inputs, not forecasts. Most new games stay below the small row. The table shows that income depends almost entirely on daily players, so getting players to return matters more than adding shop items.
